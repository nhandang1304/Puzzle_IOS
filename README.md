
# Puzzle IOS — Bird Guessing Game

A fun and interactive iOS game built with Swift and SwiftUI. Challenge yourself to identify birds from blurred images!

## About the Project

Puzzle IOS is a bird guessing game where players must identify a bird from a blurred image. You have **5 attempts** to guess the correct bird. After each incorrect guess, the image becomes progressively clearer, helping you recognize the bird.

## Features

- Guess the bird from an image.
- Progressive blur effect.
- Five attempts per puzzle.
- Native iOS user interface.
- Play again and challenge yourself.

## How to Play

1. View the blurred bird image.
2. Choose your answer.
3. If your guess is incorrect, the image becomes clearer.
4. Keep guessing with each new visual clue.
5. Guess correctly within five attempts to win!

## Built With

- **Swift** — Programming language.
- **SwiftUI** — User interface framework.
- **Xcode** — Development environment.
- **iOS** — Target platform.

## Getting Started

### Requirements

- macOS
- Xcode
- An iOS Simulator or compatible iPhone

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nhandang1304/Puzzle_IOS.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Puzzle_IOS
   ```

3. Open the `.xcodeproj` file in Xcode.
4. Select an iOS Simulator or connected device.
5. Click **Run (▶)** to build and launch the app.
